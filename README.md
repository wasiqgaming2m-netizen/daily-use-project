# Daily Use

A practical web application built with **HTML, CSS, and JavaScript** that combines contact management, video management, and a login/logout system into one simple platform.

## 🚀 Features

### 🔐 Authentication

* Login system
* Logout functionality
* Simple user interface for authentication

### 👥 Contact Management

* Add new contacts
* Edit existing contacts
* Delete contacts
* View saved contacts

### 🎥 Video Management

* Add videos
* Edit video information
* Delete videos
* Play videos
* Manage videos through an easy-to-use interface

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* JavaScript Event Handling
